# PROGRAM

A collection of my programming practice, learning notes, and implementations built throughout my journey in software development.

This repository brings together the concepts I have studied and practiced across different areas of computer science and software development. It includes exercises, small implementations, experiments, and notes that reflect my progress and understanding over time.

## Repository Structure

- **back-end/** — Backend development concepts, programming exercises, and implementations.
- **data-base/** — Database concepts, SQL, NoSQL, transactions, indexing, security, and related topics.
- **data-structures/** — Data structures, algorithms, and implementations in different programming languages.
- **front-end/** — Frontend development concepts, exercises, and implementations.
- **git/** — Git and GitHub concepts, commands, and workflows.
- **linux/** — Linux commands, system concepts, and practical exercises.
- **media/** — Media-related programming concepts and experiments.
- **os/** — Operating system concepts and implementations.
- **problem-solving/** — Programming problems, solutions, and problem-solving practice.

## Purpose

The main purpose of this repository is to document my learning journey through practical code and structured notes.

It is continuously updated as I learn new concepts, practice them, and build a deeper understanding of how software works.

> This repository represents my learning process and growth over time, rather than a collection of production-ready projects.
