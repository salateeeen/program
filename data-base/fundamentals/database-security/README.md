# SECURITY

## What Is Database Security?

**Database Security:** A set of mechanisms and practices used to protect the database from unauthorized access, modification, disclosure, or destruction.

## LEVELS OF SECURITY

1. **Network:** When we send a query to the server or receive a result from the server, we need to add **TLS** security to the TCP connection.

2. **Disk:** Before storing data on the disk, we can encrypt the data to protect it from unauthorized access.

3. **Authentication:** Determines **who the users are** and verifies their identity before allowing them to access the database.

4. **Authorization:** Determines **what each user is allowed to do** by assigning permissions and roles.
