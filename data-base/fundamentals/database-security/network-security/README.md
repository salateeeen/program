# SECURITY

## What Is Database Security?

**Database Security:** A set of mechanisms and practices used to protect the database from unauthorized access, modification, disclosure, or destruction.

TLS (Transport Layer Security): A protocol used to encrypt data while it is being transmitted between the client and the database server, this protocol comes in top of TCP.

TLS helps protect data from being read or modified while it is traveling through the network(man in the middle attack).
