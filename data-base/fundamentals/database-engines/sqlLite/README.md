# SQLITE

## What Is SQLite?

**SQLite** is an embedded database designed for storing and managing local data without requiring a separate database server.

## SQLite Features

1. **Embedded Database**: A popular embedded database for local data.

2. **BTree**: Uses B Tree as its primary storage structure, with LSM available as an extension.

3. **PostgreSQL Like Syntax**: Uses SQL syntax that is similar to PostgreSQL in many areas.

4. **Full ACID**: Supports full **ACID** transactions.

5. **Table Locking**: Uses table level locking for concurrency control.

6. **Concurrent Reads & Writes**: Supports concurrent read and write operations.

7. **Web SQL**: Has been used by Web SQL implementations in browsers.

8. **Operating Systems**: Included by default in many operating systems.
